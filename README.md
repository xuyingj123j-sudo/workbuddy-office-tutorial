## 📌 这是什么

这是一份**面向旅游企业普通员工的 AI 入门教学幻灯片**。课程不要求学员懂技术，重点讲清 AI 能做什么、不能做什么，销售、财务、行政、客服如何开始使用，以及团队怎样与 WorkBuddy 协同工作。

视觉上采用「电子杂志 × 电子墨水」风格（靛蓝瓷配色），带 WebGL 流体背景、章节幕封、数据大字报等版式，比传统 PPTX 更有质感。

> 🌊 **在线预览**：<https://xuyingj123j-sudo.github.io/workbuddy-office-tutorial/>

## ✨ 功能亮点

- **🖥️ 零门槛演示** —— 单文件 HTML，双击即开，无需 PowerPoint / Keynote
- **📱 全端适配** —— 电脑、平板、手机浏览器均可流畅翻页
- **🎨 杂志风设计** —— 靛蓝瓷主题、衬线标题、WebGL 流体背景，视觉高级
- **⌨️ 丰富交互** —— ← → 翻页、滚轮/触屏滑动、`ESC` 看索引、`B` 切静态模式（断网/低功耗可用）
- **🖼️ AI 生成配图** —— 内置 3 张编辑感杂志风配图，风格统一
- **📦 开箱即用** —— 内容完整的 13 页课件，可直接授课或二次修改

## 📚 课件内容（13 页）

| # | 页面 | 内容 |
|---|------|------|
| 1 | 封面 | AI 不是替你思考，而是替你执行 |
| 2-3 | 建立认知 | AI 的真实定位与人机分工 |
| 4-5 | 判断任务 | 高频场景与任务筛选条件 |
| 6-7 | 岗位应用 | 销售、财务、行政、客服的分工方式 |
| 8 | WorkBuddy 基础 | 模式、材料、工作空间与权限 |
| 9 | 连接器 | 办公生态与权限边界 |
| 10 | 七天行动 | 从试用到模板、专家和 Skill |
| 11 | 任务表达 | 目标、材料、规则、边界、交付 |
| 12-13 | 核心原则 + 上手 | 责任边界与五步行动 |

## 🚀 快速开始

**方式一：直接在线看（推荐）**

👉 打开 <https://xuyingj123j-sudo.github.io/workbuddy-office-tutorial/>

**方式二：本地运行**

```bash
git clone https://github.com/xuyingj123j-sudo/workbuddy-office-tutorial.git
cd workbuddy-office-tutorial
# 直接双击 index.html，或起一个本地服务器：
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

**方式三：Fork 后改成你自己的课件**

编辑 `index.html` 里的 `<section class="slide">` 内容即可，改完 `git push`，GitHub Pages 会自动更新。
